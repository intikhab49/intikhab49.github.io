03 · How I work

Fast because it's checked.

  1. 01

    Scope it in writing

    A short spec with the acceptance checks agreed before any code, so “done” means the same thing to both of us.

  2. 02

    Build in parallel

    AI coding agents and people work behind the spec, a claims board and test gates, so speed does not cost correctness.

  3. 03

    Prove the behavior

    Scripted call batteries for voice agents, end-to-end suites for apps, benchmarks for models. Results go in writing.

  4. 04

    Ship and hand over

    Deployed, documented and monitored, with the numbers that went against us reported too.
